# MiCita Salud

Proyecto de modelado funcional desarrollado para la actividad evaluativa de la asignatura Herramientas de Modelado de Software (UDES).

## Equipo
Maria Alejandra Hernandez Cubides - Código 01250371039

## Herramienta de modelado
StarUML, utilizada para la construcción del diagrama de casos de uso de la plataforma «MiCita Salud».

## Descripción
Diagrama de casos de uso que modela la gestión de citas médicas de la plataforma «MiCita Salud», incluyendo actores primarios y secundarios, relaciones de asociación, generalización, «include» y «extend».
